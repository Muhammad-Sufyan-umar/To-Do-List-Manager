# To-Do-List-Manager
Python-based To-Do List Manager with OOP concepts and file handling. This project allows users to manage daily tasks through a simple command-line interface while storing data in a text file.

## Features

- Automatic Read and Save Task.
- Mark Completed Task.
- Remove Completed Task.
- Update Task.
- Add new task
- Beginner Friendly Code.

## Technologies Used

- Python 3
- File Handling
- Object-Oriented-Programming(OOP)



## Future Improvement

- Add a GUI
